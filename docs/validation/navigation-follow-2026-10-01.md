# 快速拖动实时伸缩

2026-10-01：修正导航栏在快速拖到另一端后才伸长、拖回后才收缩的迟滞。

上一轮把拖动时的伸缩也交给了 80ms 动画和弹簧追赶，另外起步的抬升和按压动画仍在后台改变尺寸，因而手指到位后外层导航条及内部玻璃块还会变化。

现在：

- 持续拖动期间，内部玻璃块伸缩、抬升和外层导航条拉伸都直接由当前拖动距离计算，没有追赶动画。返回拖动起点时立即收回，反向过程无需等待。
- 识别拖动时冻结当前按压状态，避免到位后按压缩放继续改变尺寸。保留起步位置连续性和折射的短渐入。
- 松手或取消后才运行恢复动画。父页面确认拖动选择时不再重复播放一次点击抬升动画。
- 减少动态效果模式沿用直接切换。

测试覆盖横向、纵向：从最后一项快速拖到第一项，单次更新后立即确认变形；停留 300ms 后尺寸保持不变；立即反向拖回，同一帧内恢复起点尺寸；再次拖至第一项后松手提交，确认没有额外放大。

69 项 widget 测试全部通过，修改组件和验证脚本的静态分析通过。真实 iPhone 17 Pro / iOS 26.5 / Metal Impeller 模拟器的浅色、深色测试覆盖右→左→右的同一快速路径，检查变形值、停留时稳定性和即时返回，并保留导航折射采样验证，全部通过。结果与截图在 [navigation-follow-2026-10-01](navigation-follow-2026-10-01/)；这里验证交互连续性，不作为真机帧率测量。
