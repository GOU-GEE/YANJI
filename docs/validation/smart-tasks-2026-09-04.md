# 自然语言任务、两级科目与自动完成 · 2026-09-04

添加任务使用居中弹窗，名称下方显示识别结果或无法识别提示。支持中文数字、半小时/一个半小时、组合小时分钟、英文单位与已配置科目的常见简称。自动填充一级科目与预计分钟，手动修改优先，保存时剔除已识别时长。移除优先级和备注控件，编辑旧任务保留已有字段。

我的科目支持一级展开二级、右上角添加一级和子列表右下角添加二级，提供细分识别说明。数据库 v1→v2 仅新增可空 parent_subject_id，通过现有 Writer 和依赖解析收敛，未创建另一套统计真值。

任务时间仅从明确关联的 StudySession/Segment 累计；暂停不计，多个会话合并。达到正预计时长自动写入完成，计时继续运行。前台每秒检查，重启与回前台补判，不承诺系统挂起时即时更新界面。没有目标时长与取消任务不会自动完成。

验证：86 项应用、widget、数据库和确定性三设备测试通过；包含 v1 数据保留升级、自然输入/歧义、人工覆盖、60 分钟跨会话/暂停/重开完成与幂等、父子科目乱序到达/删除依赖收敛。flutter analyze 无问题。原生 iPhone 集成测试 1 项通过，完整走过新增二级科目→输入识别→保存→关联计时→达标完成→结束无需勾选，并截图检查明暗模式。iOS 和 Android Debug 构建通过，已覆盖安装普通 iPhone 应用并确认正常打开，用户数据保留。
