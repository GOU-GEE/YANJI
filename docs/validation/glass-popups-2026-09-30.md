# 图表信息浮层玻璃效果验证

日期：2026-09-30。

## 修改范围

一周学习折线图、科目学习时间圆环、学习热力图及完整历史页的日期详情浮层统一使用 `GlassFloatingSurface`，与横幅通知共用材质。浅色白色 / 深色 #242426，50% 不透明度，背景模糊 sigma 12，细边框使用前景色 8%。

`GlassInformationPopup` 提供 180ms 淡入淡出与 0.94–1 缩放；退出时保留最后的内容完成过渡，但立即排除读屏语义。拖动与连续选择即时更新位置和内容，不重播入场动画。重复点按当前选择可收起，折线图可通过 Escape 收起。系统减少动态效果时立即切换；浮层不拦截图表手势，仍限制在图表边界内。
