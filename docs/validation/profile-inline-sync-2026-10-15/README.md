# 同步提示移至“我的 → 设备与同步”

2026-10-15，iPhone 17 Pro 模拟器（iOS 26.5），build 18，沿用现有预览数据。

- 移除前台 15 秒待同步提醒弹窗。提示固定显示在设备列表下方，沿用设备行的玻璃容器、圆角与间距。
- 原“稍后”“同步”按钮置于信息行右侧；稍后收起详细建议，保留同步摘要。
- 按文字实际可用宽度、字体与系统文字缩放测量单行是否截断。只有截断时才提供展开箭头与点击展开，展开后可再次收起。
- 手动同步进度、成功与失败结果均留在信息行，取消同步进度对话框和结果悬浮提示。应用层持有手动同步状态，切换页面后回来仍可查看结果，并防止重复请求。
- 自动同步有新状态时替换过期的手动结果；原设备配对、编辑与删除确认保持原流程。

## 验证

7 项测试通过：3 个宽度（320、390、1200）下设备编辑、删除、非阻塞同步；320 宽正常与 1.6 倍文字下长消息展开/收起；短消息不可展开、离开页面期间同步完成与重复点击；自动状态替换旧结果。相关 6 个文件静态检查无问题。

模拟器实际验证：启动后等待超过原提醒时间未出现弹窗；我的页面的信息行、右侧按钮、展开后的完整文本均可见，运行日志无 Flutter 异常。未执行真实双端同步，本次未改变同步传输与数据合并逻辑。
