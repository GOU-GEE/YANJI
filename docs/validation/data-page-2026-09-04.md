# Data 页面重构 · 2026-09-04

设计规范：[DESIGN.md §17](../../DESIGN.md)。本记录只描述实现和验证。

## 已实现

- 顶部保留今日 / 累计 / 连续学习三指标。
- 7 天 Line/Area 趋势：周一至周日，所有过去和当天的真实点均保留；曲线控制点在相邻值范围内，不产生过冲。未来日期不画伪造零值。低时长按 15 分钟刻度，高时长按小时刻度。
- 轻触、横向拖动或读屏选点显示日期与秒级时长；固定图下 Tooltip 避免窄屏越界，并支持焦点方向键；读屏点位按周一至周日排序。
- 标题右侧为本周截至当前累计；上周整周大于零时显示增减百分比，文案明确整周比较。上周为零时不除零或显示无限增长。
- 同一张 Donut 切换本周 / 累计；中心总时长、科目实际时长与占比同步更新。可触摸扇区或科目行查看精确值；无记录时为空环；极小非零占比显示 <0.1%。科目颜色由稳定 ID 映射到命名颜色 token，重排不变色。
- 学习积累：有正时长的自然日数、最长连续学习天数、自然日日均。分母为首次学习到今天，包含零学习日；无记录时为零。
- 热力图为明确标注“后续开放”的轻量区域，未绘制模拟格子。

## 数据与边界

`StudyStatistics` 是每次读取构建的临时读模型，只遍历生产 Session / Segment 投影；无新增数据库表、写入或持久化缓存。UI 不直接访问数据库。聚合忽略不属于当前 Session 集合的孤立 Segment，将时间裁剪到快照时刻，按 Workspace IANA 时区的真实日界拆分，暂停间隔不累计。运行中记录每 30 秒更新显示，恢复前台时立即更新。

科目已移除但仍有有效 Session 时保留统计并使用回退名称，保证分项总和与总时长一致。列表时长精确到秒，概览与圆环中心按现有小时/分钟格式显示；百分比保留一位小数，分别四舍五入可能造成合计微小偏差。
