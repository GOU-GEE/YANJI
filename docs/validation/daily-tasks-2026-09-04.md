# 每日任务、自动命名与科目删除 · 2026-09-04

任务支持当日/每日互斥选中边框。名称为空且选择科目、正时长时生成“学习{科目}{分钟}分钟”。每日任务持续展示，当天时长按统计时区自然日裁剪原始片段，完成状态结合完成日期判断，午夜不擦除记录。开始学习增加取消按钮。

我的科目移除目标分控件与展示；菜单圆角，可恢复删除后从统计排除、恢复后计入。说明下方提供默认折叠的已删除科目列表，可恢复或确认彻底删除。根科目删除使子级一起隐藏；删除正在学习的科目会结束会话。彻底删除使用墓碑，不物理抹除同步日志。二级科目仅用于识别，旧记录归属一级，因此删除二级名称不扣除整个一级的学习时间。

验证：89 项应用/widget/数据库/确定性三设备回归通过；6 项迁移与业务专项复核通过，包括 v1→v3、v2→v3 保留层级与记录、跨午夜日进度、无目标每日提醒、删除/恢复统计和彻底删除依赖。静态分析无问题。原生 iPhone 集成测试 1 项通过，覆盖当日/每日边框、空标题命名、取消学习、科目删除和恢复。iOS/Android 构建成功，已覆盖更新普通 iPhone 应用，未删除用户数据。
