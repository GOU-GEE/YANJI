# 导航栏淡入灰块修复（2026-10-02）

- 用户视频：底部导航在键盘收起后从隐藏恢复，空白背景上中间短暂出现灰色矩形。
- iOS 实际渲染复现确认：半透明 Opacity 会建立离屏层，玻璃背景滤镜采样到了层内已经绘制的内容。只清除内部阴影仍然能够复现。
- 导航淡入/淡出期间使用不采样背景的基础表面，移动镜片的光学强度为零；完全显示（透明度 1）后恢复原有背景采样和镜片效果。
- 保留 260 毫秒淡入/滑入/缩放及减少动态效果设置。外侧投影用挖空内部的绘制路径，避免阴影透入透明表面。

## 验证

- 20 项导航、光学交互、页面与键盘测试通过；修改涉及的五个文件静态检查通过。
- iOS 模拟器真实渲染，在 0%、15%、40%、70%、100% 可见度下抓取图片；淡入期间空白区域的不同位置亮度差不超过 2，没有灰色矩形。完全显示时仍使用高质量玻璃渲染。
- 自定义阴影像素检查：导航内部透明且外部仍有阴影。
- 修复前实际渲染失败日志保存在 work/navigation-appearance/before-opacity-isolation.log；修复后的截图和验证结果保存在相同目录。
- 测试使用独立界面，不读取或修改用户的学习数据库。结束后安装正常应用构建，保留原有记录与配对关系。
